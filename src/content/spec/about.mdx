## ブログについて

日記をつけるのが苦手すぎるので、日記の練習と人に見せられるものを作るための文章作成練習。
嘘です、テーマがあまりに可愛くて何か書きたかったので日記の練習を書くことにしました。

## このサイトの構成

| 役割 | 使用している技術・ツール |
| --- | --- |
| 静的サイト生成（SSG） | [Astro](https://astro.build/) |
| テーマ | [Daybook](https://github.com/God-2077/astro-daybook) |
| 記事の形式 | Markdown / MDX |
| 日本語フォント | [Zen Maru Gothic](https://fonts.google.com/specimen/Zen+Maru+Gothic)（Google Fonts） |
| サイト内検索 | [Pagefind](https://pagefind.app/) |
| 執筆・記事管理 | [Obsidian](https://obsidian.md/) |
